Regla clave: la cláusula "if"
La cláusula if describe la condición (la causa). El inglés reserva will y would para la consecuencia (el resultado), nunca para la condición.
Tipo❌ Error frecuente✅ Correcto
1st If it will rain… If it rains, I will stay home.
2nd If I would have time… If I had time, I would help.
3rd If she would have studied… If she had studied, she would have passed.
¿Por qué? En la cláusula if se describe un hecho o situación (real o imaginaria), no una intención. El will/would siempre marca el resultado, no la causa. Piénsalo así: if = situación → consecuencia = will/would.
